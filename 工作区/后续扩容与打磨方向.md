# 后续扩容与打磨方向

这套漫画改编 skill 现在已经可正式使用，但还远没有到“再也不用动”的程度。当前最值得继续扩容的方向有这几块：

1. 题材分流还不够细。
   目前的主流程已经能覆盖大多数网文改编，但都市言情、古风权谋、悬疑和热血升级在页面节奏、对白密度、翻页点设计上的差异很大，后面最好拆出题材子模板。

2. 页面层自动评估还不够强。
   现在更强的是结构、长稿自然化和视觉定锚检查，后面还应该补“单页字量上限、静默页占比、跨页节奏、翻页点强弱、重复构图率”的自动审读。

3. 声场与字效体系还不够完整。
   当前已经有对白字气打磨，但漫画的阅读体验不只来自对白，还来自拟声词、字效、停顿符号、留白与气口，这一层仍值得单独做成规则包。

4. 长线伏笔校验还可以更硬。
   现在默认先落前 50 个源章节左右，这样做对样章验证很好，但如果要进一步工业化，最好新增“前段样章与全文规划对齐检查”，专门抓后段反派动机、关系逆转和伏笔回收是否提前埋好。

5. 出图之后的回归闭环还不够深。
   目前已经有角色定锚包、场景定锚包和视觉一致性检查，但真正进入批量出图后，还应该增加“服装漂移、道具缺失、场景识别度下降、镜头语言同质化”的复检环节。

6. 题材化的参考样本还不够多。
   《略施计》已经足够证明这套方法能跑通，但如果要让 skill 更稳，后面最好再补两到三部类型差异更大的小说，至少覆盖强情节、强恋爱和强群像三种形态。
