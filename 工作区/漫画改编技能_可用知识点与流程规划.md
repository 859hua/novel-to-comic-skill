# 漫画改编 Skill 可用知识点与流程规划

## 目标

这一步先锁定“漫画改编 skill 到底能继承什么、必须新增什么、绝对不能照搬什么”，再据此约束 skill 本体、样本测试和后续迭代。

当前默认目标不是把小说直接变成“会出图的 prompt 包”，而是把一部长篇网文改造成一套可连载、可分页、可分格、可继续出图的漫画项目包。

默认工作口径：

- 全文先做整体规划。
- 具体改编先落前 50 个源章节左右，必要时按自然段落微调。
- 先做样章验证，不合格不扩写。
- 每轮都必须经历“被骂、被审、被追责理论依据、被检查方法是否真用了”的闭环。

## 一、从旧的竖屏短剧 skill 可直接复用的知识点

这些不是“影视专属”，本质上是长篇改编的方法论，因此可以直接迁移。

### 1. 原作诊断优先，而不是逐章照搬

可复用原因：

- 不管改成短剧还是漫画，第一步都必须先判断原作真正的驱动引擎。
- 先抓一句话前提、主角持续欲望、主要对立网络、读者追更理由，远比立刻拆章节有用。

必须保留的诊断项：

- 一句话前提
- 主角欲望、缺陷、伤口
- 对立网络
- 情绪承诺
- 必留场面
- 必删/必压区段
- 错改风险

### 2. 先锁改编引擎，再做大纲

可复用原因：

- 改编失败通常不是因为不会写大纲，而是没先决定“这部作品靠什么让观众追下去”。
- 旧 skill 里的“改编前提、行动脊柱、关系引擎、连载承诺”这一套，漫画同样需要。

### 3. 样章先行、评估过关后再扩写

可复用原因：

- 长篇项目最怕一开始就铺满全量工作，然后到中途才发现结构、节奏、对白、载体都错了。
- 先用少量样章暴露问题，是低成本纠错。

### 4. 连续性账本

可复用原因：

- 长篇改编一旦跨多话、多场景、多道具，最容易崩的是连续性。
- 漫画比短剧更依赖外观稳定、道具状态、空间关系和人物知情差。

必须保留的账本项：

- 时间线
- 秘密/误会/知情分布
- 关系温度变化
- 服装与造型状态
- 关键道具流转
- 高价值空间状态

### 5. 方法使用审计

可复用原因：

- 这能防止我们嘴上说用了理论，实际只是写了个像样但无依据的文本。
- 也是把“参考书”和“GitHub 项目”从装饰变成约束。

### 6. 理论依据复盘

可复用原因：

- 每次迭代都写清楚“哪里好、哪里错、为什么”，才能让 skill 真正长肌肉。
- 这一步会逼我们把批评变成证据化判断，而不是感觉化发火。

### 7. 仇人视角差评 -> 编辑/导演修订

可复用原因：

- 普通创作者容易爱惜自己的结构；仇人视角能专门抓“观众根本不会等你解释”的硬伤。
- 再把情绪化差评翻译成编辑和导演语言，才能形成可执行修订。

### 8. 回原著做源场景采收

可复用原因：

- 任何大纲和总结都会把原作洗平。
- 但真正让成品有生命力的，往往是小说里那些具体动作、道具、材质、气味、关系温度和丑感、脏感、危险感。

### 9. 完整详细长稿

可复用原因：

- 真正可持续的分镜、分页、分格，不应该直接从薄大纲出。
- 必须先有一层详细到接近“重写一遍故事”的长稿，承载具体动作、空间、情绪、道具、因果和对白。

### 10. 自然化检查

可复用原因：

- 工作流味、模板味、提示词味会直接毁掉长篇阅读的生命力。
- 不把这一层清掉，后续任何分页分格都只是把假东西切得更碎。

## 二、从旧 skill 迁移时必须改造的部分

这些思路能继承，但必须改写成漫画语法。

### 1. “台词打磨”要升级成“对白 + 字气 + 气泡占位”联合检查

为什么：

- 漫画对白不仅要“说得对”，还要“放得下、读得顺、不压坏画面”。
- 同一句台词在剧本里可成立，在气泡里可能就过长、过硬、过直白。

因此必须把旧的台词打磨改成：

- 角色口吻区分
- 解释句压缩
- 可视化转译优先
- 气泡长度控制
- 单格文本密度控制
- 阅读路径不被台词打断

### 2. “分镜”不能再是影视分镜，而要改成“分页与分格叙事”

为什么：

- 影视镜头单位是 shot，漫画单位是 page / panel / gutter / page turn。
- 电影镜头感可以启发构图，但不能代替页面组织。

因此必须改成：

- 先分页，再分格
- 先锁翻页点，再锁大格
- 每页一个主节奏
- 每格一个主焦点
- 大跨页、大竖条、大静格都按页面节奏使用，而不是按镜头炫技使用

### 3. “详细长稿”必须服务于漫画页面，而不是服务于影视拍摄

为什么：

- 旧 skill 中的长稿部分容易受到影视动作调度影响。
- 漫画需要的不是机位指令，而是可切成页和格的动作、空间、情绪、物件、关系节点。

因此长稿写作时要主动避免：

- 过多机位术语
- 镜头切换式写法
- 纯导演调度口吻

### 4. 角色定锚、场景定锚、道具定锚要升级为硬性产物

为什么：

- 漫画的“连续性”很大一部分体现在视觉识别上。
- 文字里一句“他今天穿得很冷”可以过去；漫画里必须知道到底穿什么、颜色层级、版型、是否与前文连续。

### 5. Fountain 只能当辅助导出层，不能当核心契约

为什么：

- Fountain 对于节拍整理和部分工具链兼容有价值。
- 但它天然更贴近影视/剧本格式，不适合作为漫画分页分格的主承载格式。

## 三、旧 skill 中不应直接照搬的部分

### 1. 60 集、单集 3 分钟、总时长 120 分钟

原因：

- 这是短剧载体指标，不是漫画载体指标。
- 漫画要换成总话数、每话页数/屏数、阅读时长、更新节奏。

### 2. “前 15 秒钩子”这类时间单位钩子

原因：

- 漫画的对应单位应该是首屏、首格、首段阅读和翻页点，而不是秒数。

### 3. 影视 shot grammar 直接统治页面语法

原因：

- 它会把漫画做成“看起来像分镜稿的电影脚本”，而不是能读的漫画。

### 4. 导演学对镜头调度的强依赖

原因：

- 这部分在漫画里只能作为启发，不能压过 McCloud / Eisner / Framed Ink 的页面与视觉叙事原则。

## 四、从漫画相关书籍与分析报告里必须吸收的新知识点

这里优先吸收的是“可执行方法”，而不是概念名词。

### 1. 《理解漫画》可用点

必须吸收：

- 漫画用空间组织时间
- 格间空白也是叙事的一部分
- 转场类型会决定节奏和阅读速度
- 图标化与写实化比例会影响代入方式
- 角色与背景的抽象比例要服务于阅读，不是随便选

落地方式：

- 连载规划里记录每话主转场类型
- 分页脚本里标注核心翻页点
- 分格脚本里明确 panel 之间的功能差异

### 2. 《Comics and Sequential Art》可用点

必须吸收：

- 文字、气泡、画格、角色动作共同承载叙事
- 页面构成是叙事，不是装饰
- 角色表情和姿态要承担信息传达
- 字体、气泡、拟声字也是叙事设计

落地方式：

- 加入对白字气联合打磨
- 把表情矩阵、姿态矩阵纳入角色定锚包

### 3. 《Framed Ink》可用点

必须吸收：

- 构图首先服务于信息表达和情绪控制
- 明暗、形状、空间方向必须帮助读者一眼抓住主焦点
- 画面不是越花越好，而是越清楚越好

落地方式：

- 每页写“主焦点”
- 每格写“focal_point”
- 视觉一致性检查里加入焦点与可读性检查

### 4. 《Word by Word Picture Dictionary》可用点

必须吸收：

- 具体物件、具体环境、具体功能部件，能显著提高画面具体度
- 很多“看起来空”的页面，本质上是因为缺乏可画对象和环境词汇

落地方式：

- 在源场景采收里加入“物件与环境词汇采样”
- 在场景道具圣经里建立高频道具表和空间部件表

### 5. 《从文字逻辑到空间叙事》可用点

必须吸收：

- 从叙述句到画面句的转换规则
- 如何把心理、关系、气氛转成可见空间组织
- 如何避免把文学解释句硬塞成画外说明

落地方式：

- 长稿阶段强制把抽象叙述改写为动作、空间、物件、表情、间距、气泡和节奏
- 自然化检查阶段重点抓“解释性强、可视化弱”的段落

## 五、GitHub 高 star 项目里可借鉴但必须筛选的部分

外部项目只借方法，不借口号。

### 可借鉴

- 一致性资产管理
- 长链路分阶段生产
- 中间层文档化，避免“一步到位幻觉”
- 面向 panel 的记录与日志
- 工具链后端可替换

### 不能直接借

- 一条 prompt 直接出完整漫画
- 先出图再反推故事
- 把 storyboard 当最终漫画
- 把电影镜头逻辑当页面逻辑

## 六、最终流程

下面这套流程是本 skill 后续制作、样本测试、迭代审查的总准绳。

### 阶段 A：规划层

1. 规范化原作文本并拆章。
2. 锁定漫画形态。
说明：先决定条漫还是页漫、黑白还是彩色、每话页数/屏数、更新节奏和核心受众。
3. 做原作漫画改编诊断。
4. 锁定改编引擎。
说明：写清改编前提、行动脊柱、关系引擎、连载承诺。
5. 建立漫画总圣经、人物设定圣经、场景道具圣经、连载规划、连续性账本。

### 阶段 B：样章验证层

6. 先写 3 话样章长稿。
7. 先做 2 话分页脚本。
8. 先做第 1 话分格脚本。
9. 单独跑一轮对白与字气打磨。
10. 先评估，不合格不准往后写。

### 阶段 C：审查与追责层

11. 做方法使用审计。
12. 做理论依据复盘。
13. 做仇人视角差评，再转成编辑与导演修订意见。
14. 回原著做源场景采收，把被大纲洗平的动作、道具、空间、材质、关系温度捞回来。

### 阶段 D：长稿层

15. 产出完整详细长稿。
说明：详细程度要接近重写一遍小说，但书写目标是为了漫画分页分格，而不是为了影视拍摄。
16. 导出辅助性的 Fountain 稿。
17. 跑长稿自然化检查，把模板味、提示词味、工作流味、影视机位味清掉。

### 阶段 E：页面与视觉层

18. 只从通过检查的详细长稿与辅助导出稿出分页脚本。
19. 再从分页脚本出分格脚本。
20. 建立角色定锚包、场景定锚包、出图提示包。
21. 跑视觉一致性检查。

### 阶段 F：迭代层

22. 再次跑评估、方法审计、理论复盘、仇人式差评。
23. 反修 skill 规则本身。
24. 再跑样章或继续扩写。
25. 一直循环到：
  - 普通读者愿意追更；
  - 挑刺视角抓不到明显结构性硬伤；
  - 编辑视角能说明它为什么成立；
  - 漫画页面确实可读、可画、可继续生产。

## 七、当前制作原则

从现在开始，这个漫画 skill 的制作顺序必须是：

1. 先把上面的流程和知识点作为硬约束。
2. 再写 skill 本体。
3. 再跑《略施计》样本。
4. 再根据样本迭代 skill。

不允许再出现“skill 已经写了很多，但流程边界还没锁死”的情况。
