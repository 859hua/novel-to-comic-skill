# GitHub 参考判断

这里只记录“保留什么、舍弃什么”。

## StoryDiffusion

- 保留：跨图角色一致性、reference 序列管理
- 舍弃：先出图再反推故事

## wonderunit/storyboarder

- 保留：脚本到视觉草稿的中间层、快速可视化验证
- 舍弃：把影视 shot 逻辑当漫画页面逻辑

## ViMax

- 保留：长链路拆阶段、一致性检查正式化
- 舍弃：端到端一键成品幻觉

## AI Comic Factory

- 保留：文字层 / 页面层 / 出图层解耦，后端可替换
- 舍弃：单 prompt 生成漫画的产品口径

## Comicgen

- 保留：角色和表情姿态的结构化资产思路
- 舍弃：把组件拼装当作完整叙事方法

## Story2Board

- 保留：panel-level prompt logging、跨格身份稳定
- 舍弃：把 storyboard 图直接等同于漫画成稿
