# 输出合同

这个 skill 的默认交付，不是“一个梗概 + 两页分镜”，而是完整的漫画改编生产包。

## 规划层

默认产出：

- `原作漫画改编诊断.md`
- `漫画总圣经.md`
- `人物设定圣经.md`
- `场景道具圣经.md`
- `连载规划.json`
- `连续性账本.md`

### `原作漫画改编诊断.md`

至少包括：

- 一句话前提
- 主角行动脊柱
- 反对力量网络
- 情绪承诺
- 最强视觉母题
- 必留场面
- 必压缩区段
- 错改风险

### `连载规划.json`

每话至少包括：

```json
{
  "chapter": 1,
  "arc": 1,
  "title": "",
  "target_pages": 24,
  "format_route": "paged-comic",
  "source_chapters": ["第1章", "第2章"],
  "core_goal": "",
  "chapter_reward": "",
  "opening_hook": "",
  "page_turns": ["p6", "p12", "p18"],
  "ending_hook": "",
  "focus_characters": [],
  "visual_motif": "",
  "anchor_prop": "",
  "silence_or_low_text_beat": "",
  "supporting_pressure": "",
  "notes": ""
}
```

刚性要求：

- `format_route` 不能为空
- 必须有 `opening_hook`
- 必须有 `ending_hook`
- 必须有 `chapter_reward`
- 必须映射 `source_chapters`
- 必须有 `visual_motif` 或 `anchor_prop`
- 前 3 话必须明确 `page_turns`
- 前 3 话必须写 `silence_or_low_text_beat`
- 前 5 话内要让若干非主角关系压力进入 `supporting_pressure`

## 样章层

默认产出：

- `样章长稿/第001话.md`
- `样章长稿/第002话.md`
- `样章长稿/第003话.md`
- `分页脚本/第001话.md`
- `分页脚本/第002话.md`
- `分格脚本/第001话.json`

### `样章长稿/*.md`

每话至少包括：

- 话标题
- 对应原著章节
- 本话目标
- 本话外压
- 关键场景拆解
- 场景中的动作、空间、人物、道具、关键台词、话尾驱动

### `分页脚本/*.md`

每页至少包括：

- 页码
- 页面目标
- 页面主焦点
- 阅读奖励
- 翻页或转轴逻辑
- 建议格数
- 文本负载
- 是否为静默/少字页

禁止把分页脚本写成影视 shot list。

### `分格脚本/*.json`

每格至少包括：

- `page`
- `panel`
- `purpose`
- `focal_point`
- `characters`
- `action`
- `dialogue`
- `balloon_note`
- `transition`

## 审计层

默认产出：

- `对白打磨记录.md`
- `评估复盘.md`
- `技法使用审计.md`
- `理论依据评议.md`
- `仇人式负评.md`
- `编辑导演修订建议.md`
- `源场景采收卡.md`

这些文件不是附属品，而是下一轮迭代的输入。

## 长稿层

默认产出：

- `完整详细长稿总纲.md`
- `完整详细长稿/第001-010话.md` onward
- `完整详细长稿.fountain`
- `长稿自然化检查.md`

长稿标准：

- 细到接近“为漫画重写一遍小说”
- 但必须服务分页和分格
- 不能是提示词式摘要
- 不能是影视分镜转写

## 页面层

默认产出：

- `页面叙事圣经.md`
- `页面设计总表.json`
- `分页脚本/`
- `分格脚本/`

## 视觉资料层

默认产出：

- `角色定锚包/`
- `场景定锚包/`
- `出图提示包.json`
- `视觉一致性检查.md`

### `角色定锚包/*.md`

每个主要角色文件至少包含：

- 视觉一句话
- 年龄/身高/体量读取
- 轮廓与剪影
- 脸部不对称点或难忘细节
- 常用表情矩阵
- 常用体态与习惯动作
- 服装轮换
- 关联道具
- 首次进场任务
- 禁漂项

前 10 话内进入主要关系网的次要角色，也要有独立文件，不能只在人物圣经里顺带一句。

### `场景定锚包/*.md`

每个高频场景文件至少包含：

- 空间一句话
- 空间骨架与动线
- 固定地标
- 主光源与时间感
- 材质提示
- 声音/气味/温度提示
- 高频可调度动作
- 该空间最适合承载的情绪
- 禁漂项

默认至少覆盖：

- 主角旧环境
- 第一强记忆空间
- 核心生活空间
- 一处高压对抗空间

### `出图提示包.json`

至少包含：

- `style_route`
- `global_positive`
- `global_negative`
- `characters`
- `scenes`
- `props`

角色和场景条目必须引用各自的定锚文件名，避免 prompt 与 anchor 脱钩。

## 默认改编范围

如果用户没有特别指定：

- 全文都要先做整体规划
- 具体改编默认先落前 50 个源章节左右
- 如果第 50 章不是自然切点，可以顺着情绪和结构微调到更合理的断点
