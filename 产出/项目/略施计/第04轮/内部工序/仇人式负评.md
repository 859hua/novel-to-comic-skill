# 仇人式负评

这一轮终于不像拿着小说梗概硬装漫画了，但我还是要挑最疼的地方骂：

1. 你现在总算知道角色不是靠名字区分了，可是纪家后续那批功能型人物还没被彻底拉开，真往后画，仍然有撞脸和撞气质风险。
2. 纪念、纪霆舟、沈清棠、陈默这四个点已经钉住了，但你别高兴太早，真正难的是后续执行层有没有能力一直守住，不要到了第八话第十话又全画回模板脸。
3. 纪家长桌和起居区已经能分清，可你还欠“公共空间压力”的继续展开，学校、门厅、车内、医院线一多，空间记忆马上会被冲淡。
4. 你这轮把 prompt 包补上了是对的，但 prompt 一旦脱离页面目的，就会又变成美图词典。后面每次出图都得记得先服务叙事，不是服务漂亮。
